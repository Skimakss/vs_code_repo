# Финальный ml проект

## Описание
Проект посвящён предсказанию физических размеров и веса товаров  
(height, width, length, weight) по данным объявлений Avito.
Задача решается как мульти регрессия с использованием текста, изображений,
категориальных и числовых признаков, а также ансамбля моделей с OOF-стекингом.

## Идея решения
Решение построено как многоуровневый ансамбль:

1. Из текста и изображений извлекаются sparse и dense представления
2. Для каждого источника обучаются Ridge модели
3. Их OOF предсказания используются как meta признаки
4. Финальная модель CatBoost, объединяющая все сигналы

Это позволяет избежать утечек и эффективно использовать эмбеддинги.

## Используемые признаки

### Текст
- title, description, text_join (title + description)
- TF-IDF:
  - char (2–4)
  - word (1–2)
- RuBERT ("DeepPavlov/rubert-base-cased") -> dense embeddings

### Изображения
- DINOv2 embeddings

### Ручные и regex-фичи
- наличие единиц измерения (см, мм, м)
- длина текста, количество слов и цифр
- ключевые слова (шт, комплект, оптом, и т.д.)
- месяц и день недели

### Категориальные
- category_name
- subcategory_name
- microcat_name
- item_condition

## OOF-стекинг
Для каждого источника:
- Ridge Regression
- 5-fold CV
- таргеты в log1p
- сохраняются:
  - OOF-предсказания для train
  - усреднённые предсказания для test
  - усреднённые предсказания для val

## Мета-признаки
Из OOF-предсказаний размеров:
- log_volume = log_h + log_w + log_l
- log_density = log_weight - log_volume
- отношения размеров
- spread (std размеров)

## Финальная модель
CatBoostRegression, отдельная модель для каждого таргета:
- вход:
  - OOF-предсказания (TF-IDF, RuBERT, DINO)
  - мета-фичи
  - regex + числовые признаки
  - категориальные признаки
- loss: MAE
- обучение в log-шкале

## Результаты
- Валидация (10% hold-out): ~0.30x log-MAE
- Тест: 0.31x log-MAE

## Ключевые идеи
- OOF-стекинг вместо прямого использования эмбеддингов

- Совмещение текста, изображений и табличных данных
