# Семантическая сегментация кухонь (4 класса)

Проект по multi-class сегментации изображений кухонь.\
Метрика --- Dice score.\

------------------------------------------------------------------------

## Описание задачи

Необходимо сегментировать изображения кухонь на 4 класса.

Основные сложности:

-   Небольшой объем данных (120 изображений)
-   Дисбаланс классов
-   Переобучение
-   Чувствительность к подбору порогов

------------------------------------------------------------------------

# Ход экспериментов

Ниже приведена последовательность экспериментов и их влияние на итоговый
результат.

------------------------------------------------------------------------

## 1 Увеличение входного разрешения

Изменён размер входных изображений:

364×364 → 512×512

------------------------------------------------------------------------

## 2 Учет дисбаланса классов и выбор лосс-функции

Добавлены веса в BCEWithLogitsLoss, пропорциональные pixel_freq.
Пробовал разные комбинации лоссов: focal + dice, bce + dice, с разными коэффициентам.
Лучший результат остался у bce с channel_weights ~ pixel_freq

------------------------------------------------------------------------

## 3 Подбор глобального порога

Изменён threshold:

0.5 -> 0.2

Скор после 30 эпох: 0.43 Dice

------------------------------------------------------------------------

# Выбор архитектуры

Были протестированы несколько моделей (30 эпох обучения):

  Архитектура   Encoder           Dice
  ------------- ----------------- ------------
  Unet++        efficientnet-b3   0.56
  DeepLabV3     resnet50          0.50
  FPN           resnet50          0.59
  PAN           resnet50          0.55

### Выбранная модель:

FPN + ResNet50

Итоговый скор на скрытом тесте: 26 баллов

------------------------------------------------------------------------

# K-Fold и ансамбль

## 4 3-Fold кросс-валидация

-   Добавлен K-Fold (3 фолда)
-   На инференсе использован ансамбль из 3 лучших моделей

Итоговый скор: 27 баллов

------------------------------------------------------------------------

## 5 Ручной подбор порогов по классам

Подобраны разные thresholds для каждого класса.

Итоговый скор: 31 балл

------------------------------------------------------------------------

# Анализ переобучения

Добавлено логирование train_dice.

После 30 эпох (1 фолд):

train_dice = 0.904
val_dice = 0.634

Наблюдается значительный разрыв -> признаки переобучения.

------------------------------------------------------------------------

# Стабилизация обучения

## 6 CosineAnnealingLR

Добавлен scheduler CosineAnnealingLR.

Обучение стало более плавным и стабильным, однако итоговый скор за 30
эпох почти не изменился.

------------------------------------------------------------------------

## 7 Добавление аугментаций

После внедрения аугментаций разрыв уменьшился:

train_dice = 0.857
val_dice = 0.613

------------------------------------------------------------------------

# Увеличение числа эпох

## 8 Обучение 60 эпох

Метрика на тесте выросла до 37 баллов

------------------------------------------------------------------------

# Переход на 5 фолдов

## 9 5-Fold CV

-   Каждая модель обучается на большем количестве данных
-   Более аккуратно подобран learning rate
-   Валидционная метрика растёт плавнее
-   Нет деградации к концу обучения

------------------------------------------------------------------------

# Автоматический подбор порогов

## 10 Threshold tuning по OOF

Реализован автоматический подбор per-class thresholds на основе
OOF-предсказаний 5 моделей.

Итоговый скор: 40 баллов

------------------------------------------------------------------------

# Финальный результат

26 → 27 → 31 → 37 → 40

Финальный результат: 40 баллов на скрытом тесте

------------------------------------------------------------------------

# Итоговая конфигурация

-   Архитектура: FPN + ResNet50
-   Размер входа: 512×512
-   Loss: BCEWithLogits + class weights
-   Scheduler: CosineAnnealingLR
-   5-Fold CV
-   Ансамбль 5 моделей
-   Автоматический подбор порогов по OOF
-   60 эпох обучения
